{{ xc_eval_label }}

The functional itself: energy and derivative, timed in place inside the SCF

For a classical functional this is libxc's combined energy-and-derivative call; for Skala it is the network's forward pass plus the autograd backward that differentiates it. On GPU it is timed with CUDA events, because the backward is queued immediately behind the forward with no synchronization between them, and a host clock would measure kernel-launch overhead instead of work.

{{ numint_label }}

XC quadrature per iteration: grid and AO evaluation, density construction, functional evaluation, and potential assembly

Numerical integration evaluates the density and exchange-correlation model on the quadrature grid, then contracts the resulting potential back into the AO basis. Its cost can therefore grow with both the number of grid points and the size of the AO basis.

v_xc(r) = δE_xc[n] / δn(r)

Toggle the horizontal axis to distinguish grid-driven growth from basis-driven growth. Differences between the two views help identify whether quadrature size or AO contractions dominate a measured trend.

{{ jk_label }}

Coulomb and exchange matrices, the other half of the Fock build

The effective potential is the J/K build plus the exchange-correlation quadrature, so subtracting numerical integration from it leaves J/K on its own. It is a difference of two measured quantities, and it is the part of an iteration that does not depend on the functional.

End-to-end SCF time depends on the work performed in each iteration and on the number of cycles, N_SCF, required to reach convergence. Reading the panels together separates algorithmic scaling within an iteration from changes in convergence behavior.

All panels use global fixed log domains. The forward, numerical-integration, and iteration panels have independent x-axis toggles; iteration count and total cost use the number of atomic orbitals.

{{ setup_label }}

Work done once before the SCF loop, and therefore invisible in a per-iteration average: grid construction, one-electron integrals, the initial guess, and the density-fitting integral build.

{{ setup_commentary }}

Where the time goes

One SCF iteration

The stacked bands partition a steady-state SCF iteration into four directly measured, nested layers: the exchange-correlation functional itself, the rest of the quadrature around it, the J/K build, and everything else in the iteration. Because the layers nest, each band is a difference of two measurements rather than an attributed share.

Fractions use the selected compute environment and basis set and are averaged over molecules sharing an atomic-orbital count. Every stack totals 100%.

{{ composition_commentary }}

One complete SCF

The same calculation seen end to end. Setup runs once before the loop -- grid construction, one-electron integrals, the initial guess, and the density-fitting integral build -- and is amortized over however many iterations convergence takes, so its share shrinks as systems grow and grows when convergence is easy.

The measured kernel only. What a process pays before it, described under Process start-up caveats, is excluded, as is the post-loop convergence check.
