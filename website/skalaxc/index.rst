SkalaXC
========

SkalaXC is a standalone library for integrating the Skala functional into an
electronic-structure application. It accepts molecular, basis, grid, and
density-matrix inputs and evaluates exchange-correlation energies, potentials,
and nuclear gradients.

This guide is separate from the existing
`GauXC guide <https://microsoft.github.io/skala/gauxc/>`__,
:doc:`LibTorch tutorial </cpp>`, and :doc:`FTorch tutorial </ftorch>`.
Those integration paths remain available.
